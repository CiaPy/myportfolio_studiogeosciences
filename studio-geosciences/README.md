# Studio Geosciences — site

Site statique, un seul fichier (`index.html`) + le dossier `images/`.
Aucun build, aucune dépendance. Tes vraies images (extraites du portfolio)
sont déjà intégrées.

## Sections
À propos · Œuvres (3 lames + fiches techniques) · Inspirations · Observations
(schéma + glossaire) · Projets à venir · Contact.

## Mettre en ligne sur Netlify (gratuit)
1. Décompresse `studio-geosciences.zip`.
2. Sur ta page Netlify, glisse le **dossier** `studio-geosciences` dans la zone
   « Drag and drop your project folder here ».
   (Le glisser-déposer ne consomme aucun crédit.)

Pour un site séparé du portfolio actuel : passe plutôt par app.netlify.com/drop.
Renommer l'URL : Project configuration → Change site name.

## À compléter de ton côté
- Lien **Instagram** (2 endroits : coordonnées + icône du pied de page, `href="#"`).
- Pages **légales** (Mentions légales, Confidentialité, CGV — `href="#"`).

## Images non incluses (droits d'auteur)
Les visuels d'inspiration (film de Herzog, Refik Anadol, Giorgia Lupi, couverture
de livre) ne sont PAS reproduits : ce sont des œuvres tierces, risquées sur un
site commercial public. Ils figurent en références texte créditées. Si tu as les
autorisations, tu peux les ajouter toi-même.

## Modifier le texte
Tout est en clair dans `index.html`. Cherche la section voulue
(À PROPOS, ŒUVRES, INSPIRATIONS, OBSERVATIONS, PROJETS, CONTACT) et édite.
